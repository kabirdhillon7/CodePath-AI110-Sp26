# CodePath AI110 · Spring 2026 — Tech Fellow Reference Repository

## About This Repository

This repository contains my completed work for **tinker** and **show** activity in CodePath's AI110 course. As a Tech Fellow, I work through each activity before it's introduced in class — running the code, hitting the same edge cases students will encounter, and building a hands-on mental model of the material. During class, I draw on that direct experience to help students debug, reason through design decisions, and evaluate the AI-generated output they're working with.

Think of it as the preparation work that lets me mentor effectively rather than advise from a distance.

## My Role: Tech Fellow

A Tech Fellow is more than a course facilitator. I engage with the material as a practitioner — completing the same assignments, writing the same code, and encountering the same failure modes students do. In class, that translates into:

- **Pair-debugging sessions** — working through problems side-by-side, asking the right questions rather than handing over answers
- **Code review and tradeoff discussions** — helping students evaluate whether an AI-generated solution is actually correct, well-structured, and appropriate for the problem
- **Bridging fundamentals and practice** — connecting CS concepts (data structures, OOP, testing) to the AI-assisted workflows students are building fluency with
- **Mentoring engineering judgment** — the same kind of guidance a senior engineer provides to junior engineers: not just "what to do" but "how to think about it"

## About the Course

AI110 is CodePath's introduction to AI-native software engineering. Students learn to code, debug, and build in the same environment professional engineers use today — one where AI tools are part of every stage of development. The course covers Python fundamentals, object-oriented design, unit testing, Git workflows, and machine learning literacy, all practiced through an AI-integrated lens. Students build real systems, evaluate AI-generated code critically, and document their technical decisions through AI Usage Statements.

The course runs across five modules, progressing from foundational debugging and design skills through applied ML systems and a final showcase project.
